# Design

## World
Swiss Technical & Brutalist Engineering

## Palette
- Ground: `#09090b` (Zinc 950 / Deep System Black)
- Surface: `#18181b` (Zinc 900)
- Text Primary: `#fafafa` (Zinc 50)
- Text Muted: `#a1a1aa` (Zinc 400)
- Accent: `#22c55e` (Terminal Green) / `#38bdf8` (System Cyan)
- Border: `#27272a` (Zinc 800)

## Typography
- Display / Mono: 'IBM Plex Mono', monospace
- Body / Sans: 'Manrope', sans-serif

## Layout & Principles
- Strict 12-column grid structure with visible coordinate lines and border separators.
- Monospace metadata headers, zero rounded container cards, sharp corners (`border-radius: 0`).
- Generous whitespace, high-contrast typography, strict text measure (65–75ch).
